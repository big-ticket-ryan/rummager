# Rummager — Fredonia, WI edition

Live: https://big-ticket-ryan.github.io/rummager/

Mobile-first single-file community map for the village of **Fredonia** (Ozaukee County, WI). Sellers publish their public sales; shoppers see them all in one place, plan a route, and mark Visited / Revisit / Must Visit as they go.

## What's new in the Fredonia edition

- **Town-wide rezone** — map centers on Fredonia (43.470, -87.853), wider Ozaukee bbox so neighboring side roads still work.
- **Public sale publishing** — anyone can tap `+ → 🏷️ Publish a public sale`, fill in name / address / hours / items, verify the pin on the map, and broadcast to everyone in town. (One sale per device.)
- **Auto-merge** — public sales appear instantly as normal pins on every shopper's map. No "save / flag / ignore" friction.
- **NEW badge** — sales published in the last 24h get a `NEW` badge until you tap them.
- **Open hours** — sellers list date + open/close per day. Pin shows `Open now` / `Opens at HH:MM` / `Closed`.
- **Price reductions** — sellers can broadcast `$⬇ Prices reduced!` (generic) or `⚡ Lightning deals` (specific items + photos).
- **Filter dropdown** — `Filter ▾ All / Unvisited / Visited / Revisit / Must visit`. Map only shows the matching pins.
- **Search Send/blur** — Enter or 🔍 commits the search and dismisses the keyboard.
- **Route Must Visits** — the route button now plans only across `Must visit` stops.
